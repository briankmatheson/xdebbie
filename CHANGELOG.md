# Changelog

## 0.1.0 — unreleased

- qfodufk8sd: REST API, atomic JSON state, reconciler, libvirt-over-SSH driver,
  TLS and bearer-token auth.
- Scheduler: filters, reservations, overcommit, failure domains, soft and
  strict anti-affinity, spread and pack policies, dry-run.
- Lifecycle: create, start, stop, reboot, delete, self-heal, cordon, drain,
  live migration with incremental storage copy.
- capq: Cluster API v1beta2 infrastructure provider with Qfodufk8sCluster,
  Qfodufk8sMachine and their templates.
- Example: four-server cloud running a 3+4 Kubernetes cluster.
